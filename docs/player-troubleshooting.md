# 玩家疑難排解（人話版）

這份給玩家看的，遇到問題先照做，通常就會好。

---

## 1) 按「更新」一直失敗 / 卡住

先做這三件事：

1. **先把遊戲關掉**（不要讓 Minecraft 還在跑）。
2. 重開啟動器，再按一次 **更新**。
3. 網路很爛的話，晚點再試（有時候是檔案伺服器在抽風）。

---

## 2) 顯示「伺服器維護中」

這是伺服器端在維護，不是你電腦壞掉。  
已經裝好的話**照樣可以啟動**；只是維護結束前不能安裝或更新。

---

## 3) 顯示「啟動器版本過舊」

意思是：你現在的啟動器太舊，不能再用它安裝或更新。  
已經裝好的話**照樣可以啟動**；要更新請去下載最新版本的啟動器。

狀態卡上會多一行「下載網址：…」和一顆 **開啟下載頁** 的按鈕，按下去會用你的預設瀏覽器開啟啟動器的下載頁：

`https://github.com/Truhf0414/GGL_Launcher/releases`

到那裡下載最新版的安裝檔（`GGL-Launcher-Setup-<版本>.exe`）再安裝。**只從這個網址下載**，下載後怎麼確認、Windows 跳警告怎麼辦，看第 6 節。

---

## 4) 遊戲檔案壞了 / 想重新檢查一次

通常原因：

- 你本地檔案被你自己/其他模組工具改壞了
- 你曾經中途中斷更新（啟動器會顯示「上次同步沒有完成」，按 **更新** 就會接著做完）

解法：

- 打開設定，按 **檢查並修復檔案**。啟動器會逐一比對檔案，只把跟伺服器版本不一樣的換回來。

> 你可以自己改的設定（`config/`、`options.txt` 這類）：伺服器沒改過的，修復時不會蓋掉你的版本；不見的會補回來；伺服器這一版改過的，會整個換成新版。存檔、截圖不會動。  
> `mods` 資料夾裡不在伺服器清單上的檔案會列出來讓你選：**勾了才刪，沒勾就保留**。

---

## 5) 更新後「設定被重置」了

有些更新會重置 `config`（為了修 bug 或統一設定）。  
如果你很在意自己的自訂設定，請在更新前先把 `config/` 備份一份。

---

## 6) 安裝檔被 Windows 擋住（SmartScreen）

啟動器的安裝檔**沒有程式碼簽章**（要花錢買憑證，作者決定不買）。所以 Windows 的 SmartScreen 對它不認識，下載或執行時可能跳出警告，說這個檔案「不常見」或發行者未知。**這個警告本身不代表檔案有問題，也不代表檔案安全**——能相信它的依據是來源和雜湊，不是有沒有警告。

> 警告畫面的實際文字與按鈕，會因 Windows 版本而不同；發版前會在乾淨的 Windows 上實際看過一次再補進來。**最低支援的 Windows 版本也還沒確認**。以下是一般情況的做法。

### 先確認，再執行

1. **只從官方下載頁下載**：`https://github.com/Truhf0414/GGL_Launcher/releases`。看清楚整個網址；別用別人轉貼的連結、雲端硬碟或聊天室裡傳來的檔。
2. **檔名**應該是 `GGL-Launcher-Setup-<版本>.exe`，版本要跟下載頁上的那一版一致。
3. **對照 SHA-256**：下載頁每個版本的說明（Release notes）會寫這個安裝檔的 SHA-256。在存放安裝檔的資料夾開 PowerShell，執行：

   ```powershell
   Get-FileHash .\GGL-Launcher-Setup-1.0.0.exe -Algorithm SHA256
   ```

   上面的 `1.0.0` 只是範例：**請換成你實際下載的檔名**（檔名在檔案總管看得到；也可以輸入 `Get-FileHash .\GGL` 後按 Tab 自動補齊）。輸出的 `Hash` 要跟說明裡的**完全一樣**。（用 `certutil -hashfile .\GGL-Launcher-Setup-1.0.0.exe SHA256` 也可以，同樣要換成實際檔名。）

4. 雜湊對不上、說明裡沒有雜湊、或來源不是上面那個網址：**不要執行**，把情況回報給 GGL 的管理者（第 7 節）。

雜湊相符只代表你拿到的檔案，和發行者放上去的一模一樣；它不能證明檔案本身無害。

### 跳出警告時

- 如果警告視窗只有「不要執行」，先找找有沒有「其他資訊」之類的連結，點開後才會出現「仍要執行」。**只有上面三項都確認過，才選擇仍要執行。**
- 如果瀏覽器不讓你下載（說檔案不常見），同樣先確認上面的來源與雜湊，再選擇保留。
- 如果防毒軟體把安裝檔**隔離或刪掉**：不要為了讓它過關而自己關掉防毒或加排除項目，先回報給管理者。

---

## 7) 要回報問題：匯出診斷報告

遇到沒辦法自己解決的問題時，可以匯出一份診斷報告。**它只會存在你的電腦上，啟動器不會自動把它傳給任何人**；要不要分享、分享給誰，由你決定。

### 怎麼匯出

1. 打開啟動器的 **設定**，按 **匯出診斷報告**。
2. 匯出完成後，畫面會寫「已匯出診斷報告：<資料夾路徑>」，啟動器也會嘗試自動打開那個資料夾（開不開得起來，取決於你的電腦；打不開就照畫面上的路徑自己找）。
3. 資料夾通常在 `%APPDATA%\GGL_launcher\diagnostics\<日期時間>\`，每次匯出各一個資料夾。

### 資料夾裡可能有什麼

只有下面這些檔，且**不是每個都一定存在**：

| 檔                                       | 內容                                                                                                                                                                                               |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `report.json`                            | 啟動器版本、作業系統與架構、啟動器的執行檔路徑與資料夾路徑、你設定的遊戲安裝路徑、同步紀錄的版本與檔案數（或讀取錯誤）、站台網址與匯出當下抓到的站台索引（`manifest.json` 的內容）或抓取失敗的原因 |
| `sync-record.json`                       | 本機的同步紀錄：已安裝的版本與每個檔案的路徑和雜湊                                                                                                                                                 |
| `settings.json`                          | 你的啟動器設定（安裝路徑、離線玩家名稱、記憶體、除錯記錄開關）                                                                                                                                     |
| `ggl-launcher.log`、`ggl-launcher.1.log` | 啟動器的常駐記錄（事件與錯誤，就算沒開除錯記錄也會寫；`.1.log` 是剛輪替掉的舊檔）；寫入時有把使用者資料夾路徑換成 `~`，但**不保證**沒有其他個人資訊                                                |
| `launcher.log`                           | **只有開了除錯記錄才有**（在桌面）；內容比較詳細，可能含路徑與遊戲啟動指令（其中的登入憑證有遮蔽，但玩家名稱、路徑這些沒有）                                                                       |
| `rpc-launch.log`                         | **只有開了除錯記錄才有**；Discord 狀態程式的記錄                                                                                                                                                   |

**不會**自動放進去的：遊戲的 `latest.log`、`crash-reports`、你的帳號與登入憑證檔、遊戲存檔。

### 分享之前，自己先檢查

診斷報告**沒有自動去除個人資訊**。裡面常見的環境資訊包括：

- **Windows 使用者名稱**：啟動器與資料夾的路徑通常長得像 `C:\Users\<你的使用者名稱>\AppData\…`，會出現在 `report.json`，也可能出現在其他檔。
- **路徑**：你把遊戲裝在哪、資料夾名稱（可能有你的名字或其他資訊）。
- **設定與同步紀錄**：離線玩家名稱、你有哪些模組與設定檔。
- **日誌**：事件與錯誤的環境資訊。

做法：

1. 把資料夾裡的檔案**自己用記事本打開看一遍**，確認你願意讓對方看到裡面的內容。不想給的，就不要給，或自己改掉再給（先確認改完還是正常的 JSON）。
2. **不要貼到公開的地方**（公開頻道、公開的 issue、貼文）。只交給 GGL 的管理者指定、有適當權限的人。
3. 這份文件沒有指定回報的頻道或名單；**沒有被告知要送到哪裡時，先不要分享**，去問管理者。
4. 遊戲的 `latest.log`、`crash-reports` 不是預設要附的；**只有被要求時**才手動附，附之前同樣先打開檢查（遊戲日誌也可能有你的使用者名稱與路徑）。
5. 想讓管理者看到你的畫面，截圖前先看有沒有露出帳號名稱或路徑。

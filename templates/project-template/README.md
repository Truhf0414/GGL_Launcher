## Project template

Copy this folder’s contents into your new repo root.

Includes:

- `.cursor/rules/universal-guardrails.mdc`
- `.gitignore`
- `.gitattributes`
- `.prettierrc.json` / `.prettierignore` (optional)
- `eslint.config.js` (optional)

Then add project-specific rules under `.cursor/rules/`.

### Optional: standard guardrails skeleton (medium projects)

See `guardrails/SETUP.md`.
